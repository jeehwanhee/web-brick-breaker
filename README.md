# 링크의 벽돌깨기 : 하이랄 성을 되찾아라!

> 웹프로그래밍 수업 팀프로젝트 결과물

젤다의 전설 세계관을 모티브로 한 웹 기반 벽돌깨기 게임입니다.

## 스토리

여행을 떠나 있던 링크가 돌아왔을 때, 하이랄 성은 이미 가논 군단에게 점령당하고 젤다는 붙잡힌 뒤였습니다.  
링크는 하이랄 성과 젤다를 되찾기 위해 성문을 지키는 거대 나방을 시작으로, 가논의 오른팔 아그님, 그리고 마왕 가논까지 차례로 물리쳐야 합니다.

각 스테이지 진입 전에는 스토리 화면이 출력되며, 최종 스테이지 클리어 후에는 엔딩 화면을 확인할 수 있습니다.

## 주요 기능

### 게임 진행
- 프롤로그 → 3단계 스테이지 → 엔딩으로 이어지는 스토리 기반 진행
- 스테이지별 전용 배경, BGM, 벽돌 배치
- 스테이지 클리어 시 소요 시간, 피격 여부 등을 반영한 점수 산정 및 점수 breakdown 표시

### 보스 전투
| 스테이지 | 보스 | 특징 |
| --- | --- | --- |
| 1단계 | 거대 나방 (Moth) | 가루/바람 등 광역 패턴 공격 |
| 2단계 | 아그님 (Agahnim) | 화염구, 번개, 박쥐 유도탄 등 다양한 패턴 |
| 3단계 | 가논 (Ganon) | 2페이즈로 구성된 최종 보스, 삼지창·화염·충격파 패턴 |

보스는 일정 주기로 경고 후 공격 패턴을 발동하며, 투사체 반사, 유도탄 등 패턴별로 다른 회피/대응이 필요합니다.

### 스킬 (Q / W / E)
전투 중 스킬을 선택해 사용할 수 있으며, 총 8종의 스킬이 존재합니다.
- 베리어 생성 / 튕겨 내기 (방어·반격형)
- 산탄공 / 관통 공 / 연쇄 번개 / 타오르는 공 (공격 강화형)
- 시간감속 / 유체화 (상태 변화형)

### 아이템 & 성장
- 공격력 증가, 체력 회복, 공 추가, 바 확장 등의 아이템 효과 제공

### 커스터마이징
- 캐릭터 4종(blue / green / pink / red) 선택 가능, 이동이나 공격 모션 애니메이션 지원
- 공 종류 선택 가능 (부메랑 / 검 타입)
- 환경 설정에서 BGM ON/OFF 전환 가능

## 조작 방법
- `←` `→` : 캐릭터 이동
- `Q` `W` `E` : 보유 스킬 사용

## 실행 방법

별도의 설치나 빌드 과정 없이 `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

```bash
git clone https://github.com/jeehwanhee/web-brick-breaker.git
```

이후 `index.html`을 브라우저에서 직접 엽니다


## 기술 스택
- HTML5 / CSS3 / JavaScript(ES6+)
- 게임 렌더링 : HTML5 Canvas
- 외부 라이브러리, 프레임워크 없이 순수 웹 기술로만 구현

## 폴더 구조

```
web-brick-breaker/
├── index.html          # 화면(초기/설정/스토리/전투 등) 마크업
├── main.js              # 화면 전환, 스토리 데이터, 설정(캐릭터/공/BGM) 로직
├── game.js               # 핵심 게임 로직 (공/바/벽돌 클래스, 보스 패턴, 스킬, 점수)
├── gameConfig.js          # 스테이지별 벽돌 배치, 보스 패턴/애니메이션, 아이템 설정
├── style.css              # 전체 스타일링
├── audio/                 # 메뉴/스테이지/클리어 BGM
└── img/                   # 배경, 캐릭터, 보스, 공, 벽돌 등 이미지 리소스
```
